# Changelog

## 1.0.0 (2026-10-22)

First release.

- Rename all files in a folder to `Name_1`, `Name_2`, … with a live preview
- Order by file name or by date taken (EXIF for JPEG/TIFF)
- Optional leading zeros, undo, drag and drop a folder
- Installers for Windows (.exe), macOS (.dmg, Apple Silicon and Intel) and Linux (.deb, .tar.gz)
